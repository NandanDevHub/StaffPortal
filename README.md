# StaffPortal

A lightweight internal portal built with ASP.NET Core MVC for managing employee profiles, departments, and roles.  
This project serves as a modular foundation for learning and experimenting with modern CRUD patterns, layered architecture, and clean coding practices.

## Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap (UI)

## Features
- Add, edit, view, and delete employees
- Department and role management
- Layered architecture (Controllers, Services, Repositories)
- Configurable database connection

## Getting Started

### Step 1 - Clone the Repository
git clone https://github.com/NandanDevHub/TalentTrack.git

---

### Step 2 - Navigate into the Project Folder
cd TalentTrack

---

### Step 3 - Restore Dependencies
dotnet restore

---

### Step 4 - Build the Project
dotnet build

---

### Step 5 - Run the Application
dotnet run

---

### Step 6 - Open in Browser
After the server starts, open your browser and go to:
https://localhost:5001
